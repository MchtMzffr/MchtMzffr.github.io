BlueprintOutline

Navigate complex Blueprint graphs as a clean execution tree — jump to any node, filter, bookmark, and export human-readable documentation.

v1.4.0 UE 5.3 – 5.8 Editor-only Win64 / Mac
Get on Fab Watch Demo

What it does

Tree navigation

  • Exec-flow tree for events & functions
  • Double-click jump to graph node
  • Flow lanes, bookmarks, comments

Documentation (v1.4)

  • Human-readable copy/export (no K2Node noise)
  • Copy subtree or full event
  • Markdown export, optional doc panel
  • Pin tooltips (inputs/outputs)

Productivity

  • Search, regex, filters
  • Multi-BP panel support
  • Keyboard shortcuts (Ctrl+F, R, E…)

Documentation example

Readable export — variables and targets inline:

Event Fire
  Sequence
    Then 0 → Branch(Condition = true)
      False → SpawnSystemAtLocation(System Template = Decal System)
        Set Decal(Decal = SpawnSystemAtLocation)

Quick start

  1. Copy BlueprintOutline to your project's Plugins/ folder
  2. Enable in Edit → Plugins, restart the editor
  3. Open a Blueprint → toolbar BlueprintOutline or Window menu
  4. Right-click a node → Copy Subtree from Here for documentation

Full user guide ships inside the plugin: Documentation/BlueprintOutline_UserGuide_TR_EN.docx
